# 🛒 E-Commerce Website

A modern and responsive E-Commerce Website built using HTML, CSS, and JavaScript. This project provides a clean shopping interface with product pages, cart functionality, and interactive UI components.

---

## 🚀 Features

- Responsive E-Commerce UI
- Product Listing Page
- Product Details Section
- Shopping Cart Functionality
- Interactive Image Slider
- Clean and User-Friendly Design
- Fully Frontend Based Project

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

---

## 📁 Folder Structure

```txt
E-CommerceWebsite-master/
│
├── css/              # Stylesheets
├── img/              # Images and assets
├── js/               # JavaScript files
│
├── index.html        # Home page
├── cart.html         # Cart page
├── content.html      # Product content page
├── contentDetails.html
├── slider.html
└── README.md
```

## 🎯 Project Objective

The main objective of this project is to practice frontend web development and create a responsive shopping website interface using core web technologies.
